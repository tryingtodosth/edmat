# Where round 3's screenshots and repro dumps went

The round-3 review produced 212 PNGs under `shots/` and a keyboard-trace dump under `repro/` —
23 MB, and a record of one afternoon's review rather than anything the demo reads. They were left
behind when the prototype moved into this repo (2026-09-24) so that a 29 MB directory became a
6 MB one; the prose that cites them, which is the part worth keeping, is all still here.

They remain in the prototype's original home:

    /Projects/edmat-app-for-schools/prototype/docs/review/round3/{shots,repro}/

To bring them back, copy that directory in beside this file. Nothing in the code or the tests
references them — only the `.md` files in this folder do, by filename.
