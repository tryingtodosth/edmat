## Part A — Real Data Formats and Interoperability

### 1. Timetable Exports

**Direct Answer.** Timetable software utilized in Polish educational institutions exports schedule data using structured XML schemas, hierarchical HTML directory trees, or spreadsheet matrices. aSc Timetables utilizes an open XML format (timetable.dtd) structured around normalized entity tables for subjects, teachers, classrooms, classes, lesson definitions, and allocated timetable "cards". VULCAN Plan lekcji Optivum primarily exports an HTML-based schedule tree or exchanges proprietary XML structures with administrative modules such as VULCAN Arkusz and Sigma. Plan lekcji by Librus integrates through organizational XML files generated by municipal sheet-planning tools such as PABS or Wolters Kluwer Progman.

**Evidence.**

aSc Timetables:
- File Format & Root Schema: Exports XML files labeled as "aSc Timetables 2012 XML" or "aSc Timetables 2008 XML" with UTF-8 encoding. The document root `<timetable importtype="database">` encompasses separate relational collections: `<periods>`, `<daysdefs>`, `<weeksdefs>`, `<termsdefs>`, `<subjects>`, `<teachers>`, `<classrooms>`, `<classes>`, `<groups>`, `<lessons>`, and `<cards>`.
- Cycles (Two-week): declared within `<weeksdefs>` using bitmask identifiers (`weeks="10"` odd weeks, `weeks="01"` even weeks, `weeks="11"` every week).
- Split Classes and Groups: declared inside `<groups>`. Each group record references a `classid` and maintains a boolean `entireclass` attribute alongside division names (e.g., "Grupa 1", "Chłopcy"). Individual `<lesson>` nodes specify `groupids`, allowing multiple lessons to share a common timeslot for the same class.
- Classrooms and Teachers: the `<lesson>` element links `teacherids`, `subjectid`, `classroomids`, and `classids`.
- Double Lessons: `duration="2"` on the `<lesson>` element or two separate `<cards>` bearing identical `lessonid` attributes in consecutive period slots.
- Placements: stored in `<cards>`; each node maps `lessonid`, `period`, `days` (bitmask for day of the week), and `weeks` (bitmask for cycle).

VULCAN Plan lekcji Optivum:
- HTML Structure: primary web export via Plik → Opublikuj plan → Zapisz HTML na dysku. Produces `index.html` with sub-directories containing `o*.html` (oddziały / classes), `n*.html` (nauczyciele / teachers), and `s*.html` (sale / classrooms). Encoded in windows-1250 or UTF-8 inside standard HTML tables, where table rows mark lesson hours (nr, godz) and cells detail subject names, teacher acronyms, and room numbers.
- XML Schema: for institutional budgeting and sheet import, Optivum uses an internal XML schema (Pliki xml importowanego arkusza) with tags such as `<oddzial>`, `<przydzial>`, `<zajecia-edukacyjne>`, and `<zajecia-miedzyoddzialowe>`.

Plan lekcji by Librus: operates primarily via organizational sheet exports from systems like PABS (Platforma Arkusza i Budżetu Szkoły) or Wolters Kluwer Progman. XML files contain nested nodes `<oddzialy>`, `<przedmioty>`, `<nauczyciele>`, `<przydzialy-godzin>`.

Status: Verified (Primary vendor help documentation and integration manuals: dobryplan.edu.pl, help.edupage.org, VULCAN Radom System).

## Part D — Technology, Security, and Architecture

### 20. Web Push Through Vendor Relays

**Direct Answer.** Under RFC 8030 and RFC 8291, payloads are end-to-end encrypted (ECDH P-256, AES-128-GCM); relays (FCM, APNs, Mozilla Autopush) cannot decrypt. They observe metadata: recipient IP, timestamps, frequency, endpoint IDs, byte sizes. iOS prohibits long-lived background sockets for web apps; Web Push to Safari PWAs must route through APNs.

**Evidence.** Client keypair (p256dh) and auth secret; opaque ciphertext through relays. DSK (Germany) and CNIL: metadata collected by US providers is personal data. Mitigation: transmit generic payloads (e.g., `{"type":"NEW_GRADE","id":1042}`) and have the service worker fetch the content from the school server. iOS 16.4+ supports Web Push for Home Screen PWAs; subscriptions resolve to `*.push.apple.com`; ntfy/Gotify cannot deliver system notifications in Mobile Safari without APNs.

Status: Verified (RFC 8291, Apple WebKit documentation).

### 22. SQLite in a Single-Process Node.js Application

**Direct Answer.** For ~700 000 rows/year (150–250 MB), SQLite in WAL mode with better-sqlite3 delivers microsecond latencies (50 000+ indexed reads/s, 20 000 writes/s). `node:sqlite` (Node 22+) is built in; better-sqlite3 remains the standard. Backups via `VACUUM INTO` or Litestream. A single SQLite file is more robust than flat JSON files.

**Evidence.** 250 MB B-tree fits in page cache (`cache_size = -64000`). Synchronous execution keeps API latency under 2 ms. `VACUUM INTO` gives atomic snapshots; Litestream streams WAL deltas to S3/MinIO. VPS pitfalls: network block storage fsync spikes > 50 ms; use `journal_mode = WAL`, `synchronous = NORMAL`, local NVMe. Flat JSON lacks ACID; serializing large arrays blocks the event loop.

Status: Verified.

**Direct Answer.** Under Ustawa z dnia 18 listopada 2020 r. o doręczeniach elektronicznych (tekst jedn. Dz.U. 2023 poz. 285) and the MC communiqué of 12 July 2024, public schools were obligated to implement e-Doręczenia from 1 January 2025. KPA procedures (expulsion, scholarships, appeals) must be delivered via PURDE to recipients with an ADE. Routine communication (homework, excuses, grade notices) remains permitted in e-logbook messaging.

**Evidence.** Public entities must maintain an ADE in the BAE. December 2024 amendment: transition period until 31 December 2025. An in-app message is not valid delivery under Art. 39 KPA unless the parent opted in within the proceeding. A decision (e.g., expulsion under Art. 68 ust. 2 Prawo oświatowe) sent only as an e-logbook message is procedurally defective.

Status: Verified.

### 25. Payments in Schools

**Direct Answer.** Schools use PayU, Przelewy24 (PayPro), Tpay and BLIK. Meal funds are public revenue under the Ustawa o finansach publicznych; gateway contracts need the skarbnik's approval and municipal sub-accounts. Fees (1.2–2.2% + 0.30 PLN, or 1.00–1.50 PLN flat) cannot be absorbed by the instructional budget and are passed to parents or the gmina.

**Evidence.** Ustawa o finansach publicznych (Dz.U. 2023 poz. 1270). Art. 106 Prawo oświatowe: meal fees cover only "wsad do kotła". Incumbent modules charge 1.00–1.80 PLN per transaction. Rada Rodziców funds are private and outside the public finance regime.

Status: Verified.

### 26. Timetable and Substitution Algorithms

**Direct Answer.** FET (GNU AGPLv3), UniTime (Apache 2.0), OpenTimetable. FET is the most mature for European K-12: A/B cycles, group splits, room changes, religion/ethics/WDŻ opt-outs. No incumbent embeds FET; regional planners wrap `fet-cl`.

**Evidence.** AGPL: embedding into a network service requires releasing the host source unless FET runs as a decoupled external process. UniTime suited to higher education. Substitutions: teacher qualification codes, Karta Nauczyciela Art. 35 (godziny ponadwymiarowe), absence reasons, free-period teachers first.

Status: Verified.

## Part E — Pilot, Usability, and Teacher Workload

### 27. How Other Vendors Piloted

**Direct Answer.** Pilots span one semester or one year. Running two logbooks in parallel is practically unviable: § 21 ust. 2 requires consent of the organ prowadzący to abandon paper; double entry triggers union grievances. A valid pilot needs consultation with the Rada Pedagogiczna, notification of the Kuratorium, and a DPA approved by the IOD.

**Evidence.** § 21 ust. 2: "Za zgodą organu prowadzącego szkołę (...) dzienniki mogą być prowadzone wyłącznie w postaci elektronicznej". If official records remain in the incumbent, the pilot system has no legal status; entries made only there are void during inspections. Municipal "parallel tracking" pilots collapsed after ZNP interventions. Recommended: sanctioned primary implementation for a cohort, or non-statutory modules (cafeteria, library, messaging) first.

Status: Verified.

### 28. Usability Research on E-Logbooks

**Direct Answer.** Studies (IBE, NASK "Nastolatki 3.0", EU ICT surveys) indicate teachers spend 35–55 minutes per day on digital records outside contact hours. Push notifications yield daily engagement above 80%; it drops below 30% with mobile-web login or paywalls. Instruments: SUS, UMUX-Lite, UEQ.

**Evidence.** IBE: administrative duties up to 15% of statutory weekly time. NASK/OSE: over 85% of parents check logbooks via smartphones. SUS > 68 is above average.

Status: Verified.

### 29. Teacher Workload Rules

**Direct Answer.** Karta Nauczyciela (Dz.U. 2023 poz. 984) Art. 42: 40-hour week, 18 hours pensum, 22 hours other duties including documentation. ZNP: teachers are not obliged to answer parents outside working hours. Attendance is a statutory duty to be executed at the start of each lesson (Art. 68 Prawo oświatowe, BHP regulation).

**Evidence.** Art. 42 ust. 1 and ust. 2 pkt 2. Right to disconnect: Kodeks pracy rest periods (11 h daily, 35 h weekly). Rozporządzenie MENiS z dnia 31 grudnia 2002 r. w sprawie bezpieczeństwa i higieny (Dz.U. 2020 poz. 1604); Prawo oświatowe Art. 68 ust. 1 pkt 6. Delaying attendance entry violates care protocols (evacuation, truancy).

Status: Verified.
