## What is in it

- **Three left-open gaps closed** (§17AQ/§17AS follow-up):
  - A real SQLite collation (`backend/config/dblocale.py`, registered the same way as the existing
    `edmat_fold` search collation in `taxonomy/apps.py`'s `ready()` — no migration, no new
    dependency) so exercise-title sort puts a diacritic next to its base letter instead of past
    `z`.
  - The activity feed's `?content_locales=` narrowing now judges each row by its own actual
    content language (a translation/solution-entry's own `source` locale, not just the linked
    exercise's), with the same `X-EdMat-Hidden-Languages` header every other list already sends.
  - The rich editor (Tiptap) now renders live KaTeX for an equation while editing instead of raw
    `\( \)`/`\[ \]` text, and gained real table editing (insert/add-row/add-column/delete) — a UI
    addition only; storage/read pipeline were already able to hold `<table>` markup. **New
    frontend dependency**: `@tiptap/extension-table` + its `-cell`/`-header`/`-row` siblings
    (MIT), already inside this bundle's built `frontend/build/` — nothing to install server-side.
- **Guardian accounts: suspend/reactivate a child's account without deleting it** (§17AP
  follow-up) — `PATCH /api/auth/children/{id}/ {is_active}` toggles `User.is_active`, which
  Django's `authenticate()` and DRF's `TokenAuthentication` already refuse on, so a suspend takes
  effect on the child's very next request. No new field, no migration — `is_active` already
  exists on every Django user.
