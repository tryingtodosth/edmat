# EdMat — the 2026-08-28 update for webek4.fuw.edu.pl / edmat.net

**Scope: a routine update automated by `deploy/fuw/*.sh` — but NOT purely additive this time.**
One migration (`exercises.0011`) **drops two columns** (`ExerciseTranslation.hint` / `.solution`)
after `exercises.0010` has copied their text into the new `SolutionEntry` table. The step-0
database backup is therefore not a formality for this bundle: it is the only way back past that
drop. No new environment variables, no new Python packages, no Apache/vhost change. **One new
Django app (`activity`)** — arrives in the ordinary backend rsync, already in `INSTALLED_APPS`.

**If the 2026-08-26 bundle (`-d`) was the last applied, this contains everything since.** Two
features, both designed in owner Q&As on 2026-08-27 (root `CLAUDE.md` §17AH–§17AI):

## What is in it

- **The solution/hint pool** — an exercise now carries any number of peer hints and solutions
  instead of one text field of each: written by named people in one language each, ▲/▼-voted
  (verified-contributor weight 2×), pinned corpus originals first, each with its own discussion,
  reports, and edit suggestions (decided by the entry's author + staff/governors). A verified
  contributor / staff / governor publishes immediately; anyone else's entry waits for ONE
  reviewer accept (a decline requires a note). The moderation queue gained a "Solutions & hints"
  tab; translations narrowed to title/statement/answer. **`Exercise.verified` is DERIVED now**
  (≥1 published solution that passed review) — on this corpus that flips it from 353 to 742 of
  746, an owner-accepted change of meaning ("a reviewed/original solution exists"), so do not
  read the jump as a data error.
- **The activity feed + anchored micro-posts** — `/activity`: a stored, public-by-construction
  event log (new content at publish, reviews/claims/comments on public targets, new
  courses/events/listings), filters in the URL, a Followed view (followed tags + course
  membership), burst grouping, "load more", and 90-day self-trim. Signed-in users can publish
  **posts**: words + a required discipline/branch/tag anchor + optionally one referenced
  exercise/material/course + an optional image (re-encoded server-side, EXIF stripped, never the
  uploaded bytes — the avatar/event-picture pipeline). 12/hour per-account posting throttle.
  **Kill switch: `posts`**, seeded ON by `moderation.0026` — turning it off removes the composer,
  the post pages AND every post row from the feed. The homepage's last tab is the feed's newest
  slice.

## Migrations — read the first row before running

| Migration | Does |
|---|---|
| `exercises.0009` | the `SolutionEntry` + `SolutionEntryVote` tables |
| `exercises.0010` | **data**: copies every translation's hint/solution into pinned/pending pool entries, then recomputes the derived `verified` (353 → 742 on this corpus — intended) |
| `exercises.0011` | **DROPS `ExerciseTranslation.hint` and `.solution`** — irreversible past the step-0 backup |
| `moderation.0023`–`0024` | nullable `EditSuggestion.entry` FK; retargets/closes pending hint/solution suggestions |
| `moderation.0025`–`0026` | the `posts` key in `FeatureFlag.key` choices; seeds the row on |
| `notifications.0011`–`0012` | the two `solution_entry_*` types; nullable `Notification.post` FK |
| `activity.0001`–`0002` | the `ActivityEvent`/`Post` tables; **data**: backfills the feed from the last 90 days of published content (reads each content table once — milliseconds here) |

Everything except `exercises.0011` rolls back with `migrate <app> <previous>`; `0011` needs the
step-0 `~/edmat-db-backup-*` copy. `apply-on-server.sh` takes that backup unconditionally.

## Steps

Exactly the table in `deploy/fuw/README.md`:

1. On this VM (already done for this bundle): `bash deploy/fuw/pack.sh` → `FUW/UPDATE-20260828.tar.gz`.
2. On the host: `bash deploy/fuw/transfer.sh FUW/UPDATE-20260828.tar.gz`.
3. On webek4 as `todoonet`:
   `tar xzf UPDATE-20260828.tar.gz && bash UPDATE-20260828/deploy/fuw/apply-on-server.sh`
   — backup, rsync, pip (no-op), migrate, permissions, Apache restart, smoke test. The smoke
   now checks all three of this release's seams (pool shape on an exercise detail, a non-empty
   `/api/activity/`, the seeded `posts` flag).
4. Authenticated smoke: `EDMAT_EMAIL=… EDMAT_PASSWORD=… bash UPDATE-20260828/deploy/fuw/smoke.sh`.
